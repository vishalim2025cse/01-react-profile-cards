# Project 1 – Profile Cards

A beginner-friendly React project built with Vite.

## Run the project

1. Extract the ZIP file.
2. Open the extracted `01-profile-cards` folder in VS Code.
3. Open the terminal in that folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown in the terminal (usually http://localhost:5173).

## Components

- `Header.jsx` – displays the page heading.
- `ProfileCard.jsx` – reusable student profile card; receives data through props.
- `Footer.jsx` – displays the footer.
- `App.jsx` – imports and combines the components.

Try changing the student names, roles, and skills in `src/App.jsx`.
